# 배포 가이드

운영 환경에 DataBridge를 배포하기 위한 설정 및 점검 절차입니다.

---

## 필수 변경 항목

`.env.example`을 복사하여 `.env` 파일을 생성한 후, 아래 항목들을 **반드시** 운영 환경에 맞게 변경하세요.

### 보안 관련 (필수)

| 변수명 | 기본값 (개발용) | 운영 환경 권장 |
|--------|----------------|---------------|
| `ADMIN_PASSWORD` | `admin1234` | 12자 이상, 대소문자+숫자+특수문자 조합 |
| `SECRET_KEY` | `databridge-secret-key-change-me` | 무작위 64자 이상 |
| `WEBHOOK_SECRET` | `changeme` | 무작위 32자 이상 |
| `POSTGRES_PASSWORD` | `admin1234` | 강력한 비밀번호 |

#### 비밀키 생성 방법

**Linux/macOS:**
```bash
openssl rand -hex 32        # SECRET_KEY (64자 hex)
openssl rand -hex 16        # WEBHOOK_SECRET (32자 hex)
# 또는
python -c "import secrets; print(secrets.token_hex(32))"
```

**Windows (PowerShell):**
```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

### 경로 설정 (필수)

| 변수명 | 설명 | 예시 |
|--------|------|------|
| `WATCH_DIR_HOST` | 감시할 공유 폴더의 **호스트 경로** | `/mnt/shared/data` (Linux), `C:/SharedData` (Windows) |

> `WATCH_DIR`은 컨테이너 내부 경로(`/data`)이므로 변경하지 마세요.

## Ollama 서비스 운영화

Ollama는 Docker 외부에서 실행되므로, 부팅 시 자동 시작 설정이 필요합니다.

### Linux (systemd)

```bash
sudo cp scripts/ollama.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable ollama
sudo systemctl start ollama
sudo systemctl status ollama
```

### Windows

**방법 A: 시작 프로그램 등록** — `ollama serve` 실행 배치 파일 생성

**방법 B: NSSM 서비스 등록 (권장)**
```powershell
choco install nssm
nssm install Ollama "C:\Users\<사용자>\AppData\Local\Programs\Ollama\ollama.exe" serve
nssm start Ollama
```

### 모델 다운로드

```bash
ollama pull exaone3.5:7.8b      # 한국어 최적
ollama pull qwen2.5:7b           # 대안
ollama list                      # 확인
```

## 네트워크 설정

### 컨테이너 → Ollama 연결

| 환경 | `host.docker.internal` 지원 |
|------|---------------------------|
| Docker Desktop (Win/Mac) | 기본 지원 |
| Linux Docker Engine | `extra_hosts` 추가 필요 |

```yaml
# Linux Docker Engine: docker-compose.yml에 추가
services:
  app:
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

### 방화벽

| 포트 | 서비스 | 외부 노출 |
|------|--------|----------|
| 8501 | Web UI (Streamlit) | 필요 |
| 5432 | PostgreSQL | 불필요 (내부용) |
| 5433 | 외부 PostgreSQL (테스트) | 불필요 (내부용) |
| 8000 | ChromaDB | 불필요 (내부용) |
| 11434 | Ollama | 불필요 (로컬만) |

## 배포 점검 체크리스트

### 사전 준비

```
[ ] Ollama 설치 + 모델 다운로드 완료
[ ] Ollama 서비스 실행 중
[ ] .env 파일 설정 완료 (보안 값 변경)
[ ] WATCH_DIR_HOST 경로 존재 및 권한 확인
```

### 서비스 시작

```bash
docker compose up -d
docker compose logs -f          # 에러 확인
docker compose ps               # 모든 서비스 healthy 상태 확인
```

### 연결 확인

```
[ ] 브라우저 http://<서버IP>:8501 접속
[ ] admin 로그인 성공
[ ] 채팅 페이지 표시
```

### 기능 테스트

1. **파일 감시**: 공유 폴더에 CSV 복사 → 채팅에서 "등록된 테이블 보여줘"
2. **SQL 조회**: "이번 달 매출 합계 구해줘"
3. **문서 검색**: PDF 복사 → "보고서 내용 찾아줘"
4. **승인**: "마트 만들어줘" → 승인 관리에서 확인
5. **외부 DB** (선택): 설정 > 시스템 상태 > 외부 DB 연결 + 스키마 동기화

### 최종 체크리스트

```
[ ] 파일 업로드 → DB 적재 정상
[ ] SQL 조회 정상 (SELECT)
[ ] 문서/이미지 검색 정상
[ ] 승인 워크플로우 정상
[ ] 감사 로그 기록 확인
[ ] 알림 시스템 동작 확인 (선택)
```

## 문제 해결

### Ollama 연결 실패

```bash
curl http://localhost:11434/api/tags
docker compose exec app curl http://host.docker.internal:11434/api/tags
```
→ Ollama 서비스 재시작, Linux `extra_hosts` 설정 확인

### 파일 감시 안 됨

```bash
docker compose exec app ls -la /data
docker compose logs app | grep -i watcher
```
→ `WATCH_DIR_HOST` 경로 및 마운트 권한 확인

### DB 연결 실패

```bash
docker compose ps postgres
docker compose logs postgres
```
→ `.env`의 `POSTGRES_*` 설정 확인

### 메모리 부족

```bash
docker stats
```
→ 최소 16GB RAM 권장, 경량 모델 사용 고려

## 운영 .env 템플릿

```bash
# === 감시 폴더 ===
WATCH_DIR_HOST=/mnt/nas/shared_data
WATCH_DIR=/data

# === 데이터베이스 ===
POSTGRES_DB=databridge
POSTGRES_USER=databridge
POSTGRES_PASSWORD=<강력한_비밀번호>

# === AI 모델 ===
OLLAMA_HOST=http://localhost:11434
LLM_MODEL=exaone3.5:7.8b

# === 에이전트 ===
AGENT_MAX_QUERY_ROWS=5000
AGENT_QUERY_TIMEOUT=30
MART_PREFIX=mart_

# === 알림 ===
NOTIFICATION_ENABLED=true
NOTIFICATION_TIMEOUT=10

# === 인증 ===
ADMIN_PASSWORD=<강력한_비밀번호>
SECRET_KEY=<무작위_64자>
WEBHOOK_SECRET=<무작위_32자>

# === 외부 DB (선택) ===
EXTERNAL_DB_ENABLED=false
# EXTERNAL_DB_NAME_ALIAS=erp
# EXTERNAL_DB_HOST=외부DB호스트
# EXTERNAL_DB_PORT=5432
# EXTERNAL_DB_NAME=company_erp
# EXTERNAL_DB_USER=readonly
# EXTERNAL_DB_PASSWORD=xxxxx

# === 앱 ===
APP_PORT=8501
```
