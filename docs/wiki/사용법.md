# 사용법

## 데이터 올리기

데이터를 넣는 방법은 아래와 같습니다.

### 방법 1 — 공유 폴더 (가장 기본)

공유 폴더(`WATCH_DIR`) 안에 파일을 넣으면 됩니다. 하위 폴더를 자유롭게 만들 수 있습니다.

```
📁 /data/
  ├── 매출/
  │   ├── 2025년1월_매출.xlsx     ← 엑셀, CSV 넣으면
  │   └── 2025년2월_매출.csv        DB 테이블로 자동 적재
  ├── 보고서/
  │   ├── 시장분석_2025Q1.pdf     ← PDF, 한글, Word, PPT 넣으면
  │   ├── 기술검토_보안.hwp          벡터 검색에 자동 등록
  │   └── 발표자료.pptx
  ├── 사진/
  │   ├── 현장사진_001.jpg        ← 이미지 넣으면
  │   └── 제품사진_A.png            AI 유사 검색 + EXIF 분석 등록
  └── 로그/
      └── 서버로그_0210.csv       ← 무슨 파일이든 알아서 분류
```

#### 파일 종류별 처리

| 파일 종류 | 처리 방식 | 예시 |
|---|---|---|
| **엑셀 (.xlsx, .xls)** | 시트별로 DB 테이블로 변환 | 매출현황.xlsx → `매출현황` 테이블 |
| **CSV / TSV** | DB 테이블로 변환 | sales_202502.csv → `sales_202502` 테이블 |
| **JSON** | DB 테이블로 변환 | api_data.json → 테이블로 변환 |
| **PDF** | 텍스트 추출 → 검색 등록 | 보고서.pdf → 채팅에서 내용 검색 가능 |
| **한글 (.hwp, .hwpx)** | 텍스트 추출 → 검색 등록 | 기안서.hwp → 채팅에서 내용 검색 가능 |
| **Word (.docx, .doc)** | 텍스트 추출 → 검색 등록 | 회의록.docx → 채팅에서 내용 검색 가능 |
| **PPT (.pptx, .ppt)** | 텍스트 추출 → 검색 등록 | 발표자료.pptx → 채팅에서 내용 검색 가능 |
| **이미지 (.jpg, .png 등)** | DINOv2 임베딩 + EXIF 추출 | 현장사진.jpg → 유사 검색, 중복 탐지 |

> 💡 파일을 넣으면 보통 **몇 초~1분 이내**에 자동으로 처리됩니다.
> 처리 상태는 채팅에서 `"최근 등록된 파일 목록"` 으로 확인할 수 있습니다.

> 📌 엑셀 파일이지만 내용이 보고서 형식(텍스트 위주)인 경우, 스마트 분류가 자동으로 문서로 처리합니다.

### 방법 2 — FTP/SFTP 서버 훅 (예정)

## 채팅으로 조회하기

### 데이터 조회

```
"이번 달 매출 보여줘"
"제품별 매출 합계를 내림차순으로"
"지난달 대비 매출이 줄어든 항목은?"
"customers 테이블에서 서울 거주 고객 수는?"
```

### 문서 검색

```
"보안 관련 보고서 찾아줘"
"최근 올라온 문서 목록 보여줘"
"계약서에서 해지 조건 관련 내용 찾아줘"
"지난 분기 실적 보고서 요약해줘"
```

### 이미지 검색

```
"현장사진_001과 비슷한 사진 찾아줘"      ← 유사 이미지 검색
"이미지를 그룹별로 분류해줘"              ← 자동 클러스터링
"중복 사진 있는지 확인해줘"               ← 중복 탐지
"등록된 이미지 목록 보여줘"               ← 이미지 목록
"현장사진_001 촬영 정보 보여줘"           ← EXIF 메타데이터 조회
```

### 복합 질의 (DB + 문서 동시 검색)

```
"매출이 떨어진 제품이 있어? 관련 보고서도 있으면 찾아줘"
"신규 고객 수 추이를 보여주고, 마케팅 보고서에서 관련 분석도 찾아줘"
```

> 복합 질의는 DB 조회와 문서 검색을 동시에 실행한 뒤, LLM이 결과를 종합 분석합니다.

### 데이터 현황 파악

```
"지금 어떤 테이블들이 있어?"
"sales 테이블 구조 보여줘"
"등록된 문서가 몇 개야?"
```

## 마트 구축하기

채팅으로 분석용 테이블(마트)을 만들 수 있습니다.

### 마트 생성

```
"월간 제품별 매출 마트 만들어줘"
"고객별 최근 3개월 구매 이력 테이블 만들어줘"
"지역별/카테고리별 매출 요약 테이블 만들어줘"
```

에이전트가 SQL을 생성하면 사용자가 확인하고 **[승인]** 버튼을 클릭해야 실행됩니다.

```
🤖 아래 마트를 생성할까요?

   CREATE TABLE mart_monthly_product_sales AS
   SELECT ...

   ⏸️ [승인] [SQL 수정] [취소]
```

### 마트 관리

```
"지금 만들어진 마트 목록 보여줘"
```

> 모든 마트는 `mart_` 접두사로 생성됩니다.
> 에이전트는 기존 원본 테이블을 변경할 수 없습니다.

## 배치 작업 등록하기

반복적인 데이터 작업을 자동화할 수 있습니다.

### 배치 등록

```
"매일 아침 7시에 전일 매출 요약 만들어줘"
"매주 월요일에 주간 보고서용 데이터를 정리해줘"
"매월 1일에 전월 마감 테이블을 갱신해줘"
```

### 배치 관리

```
"등록된 배치 목록 보여줘"
"daily_sales_summary 배치 실행 이력 보여줘"
"weekly_report 배치 중지해줘"
```

> 배치 작업은 크론 표현식으로 스케줄됩니다 (예: `0 7 * * *` = 매일 07:00).
> 실패한 배치는 자동 재시도하지 않으며, 이력과 에러 로그가 기록됩니다.

## 데이터 관리하기

웹 UI의 **📁 데이터 관리** 페이지에서 등록된 데이터를 관리할 수 있습니다.

### 3개 탭

| 탭 | 기능 |
|---|---|
| **📊 테이블** | 등록된 테이블 목록 조회 (이름, 소스 파일, 행 수, 컬럼 수, 설명), 삭제 요청 |
| **📄 문서** | 등록된 문서 목록 조회 (이름, 소스 파일, 파일 형식, 청크 수), 삭제 요청 |
| **🖼️ 이미지** | 등록된 이미지 썸네일 조회 (이름, 크기, 카메라 정보), 삭제 요청 |

### 삭제 워크플로우

1. 사용자가 **🗑 삭제 요청** 버튼 클릭
2. 승인 요청이 생성됨 (즉시 삭제되지 않음)
3. 관리자가 **✅ 승인 관리** 페이지에서 확인
4. **[승인 & 삭제]** 클릭 시 DB, ChromaDB, 카탈로그, 원본 파일에서 모두 삭제

> ⚠️ 삭제는 되돌릴 수 없습니다. 관리자 승인 단계에서 신중하게 확인하세요.

## 승인이 필요한 작업

| 작업 | 승인 필요 | 설명 |
|---|---|---|
| **데이터 조회 (SELECT)** | ❌ 불필요 | 바로 실행. 읽기만 하므로 안전 |
| **문서 검색** | ❌ 불필요 | 바로 실행 |
| **이미지 검색** | ❌ 불필요 | 바로 실행 |
| **마트 생성 (CREATE TABLE)** | ✅ **필요** | SQL 확인 후 [승인] 클릭 |
| **배치 작업 등록** | ✅ **필요** | SQL + 스케줄 확인 후 [등록] 클릭 |
| **리소스 삭제 (테이블/문서/이미지)** | ✅ **필요** | 관리자 확인 후 [승인] 클릭 |

> ⚠️ **Human-in-the-Loop**: 에이전트가 생성한 SQL은 사용자가 **직접 확인하고 승인**해야만 실행됩니다.
