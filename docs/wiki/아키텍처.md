## 에이전트 시스템

### 오케스트레이터 인텐트 분류

`orchestrator.py`는 다단계 하이브리드 방식으로 사용자 질의의 의도를 분류합니다.

```
사용자 질의
    │
    ▼
1. 리스트/메타 패턴 매칭 (키워드 기반)
    │  "테이블 목록", "문서 목록" → list_tables
    │  "테이블 구조", "컬럼 정보" → meta
    │
    ▼
2. 마트/잡 키워드 매칭
    │  "마트 만들어", "테이블 생성" → create_mart
    │  "배치 등록", "스케줄" → manage_job
    │
    ▼
3. 키워드 점수 산출
    │  data_score (SQL 관련 키워드 점수)
    │  doc_score (문서 관련 키워드 점수)
    │  image_score (이미지 관련 키워드 점수)
    │
    ▼
4. 복합 판단
    │  data_score ≥ 2 AND doc_score ≥ 2 → composite
    │
    ▼
5. LLM 폴백 (분류 불확실할 때)
    │
    ▼
라우팅: sql_agent / doc_agent / image_agent / composite / create_mart / manage_job
```

### 에이전트별 역할

| 에이전트 | 파일 | 역할 |
|---|---|---|
| **SQL Agent** | `sql_agent.py` | 자연어 → SQL 생성 → SELECT 실행 → 결과 반환 |
| **Doc Agent** | `doc_agent.py` | 자연어 → ChromaDB 벡터 검색 → 관련 문서 반환 |
| **Image Agent** | `image_agent.py` | 유사 검색 / 그룹핑 / 중복 탐지 / 목록 / EXIF 조회 |
| **Mart Builder** | `tools/create_mart.py` | 스키마 분석 → CREATE TABLE AS SELECT 생성 |
| **Job Manager** | `tools/manage_jobs.py` | 배치 작업 CRUD + 수동 실행 |

## 이미지 처리 파이프라인

### 인제스트 (등록)

```
이미지 파일 → EXIF 추출 → DINOv2 임베딩 (384차원) → ChromaDB 저장
                                                    → 썸네일 생성
                                                    → catalog_images 등록
```

### 검색/분석

| 기능 | 방식 |
|---|---|
| **유사 검색** | ChromaDB cosine similarity → 유사도 순 정렬 |
| **클러스터링** | AgglomerativeClustering (cosine, average linkage) |
| **중복 탐지** | Union-Find on pairwise cosine similarity matrix |

- DINOv2: Meta의 ViT-S/14 모델, 384차원 벡터
- ChromaDB `images` 컬렉션: `embedding_function=None` (사전 계산된 임베딩 직접 저장)
- 유사도 임계값: `.env`의 `IMAGE_SIMILARITY_THRESHOLD` (기본 0.98)

## 외부 DB 플러그인 시스템

외부 PostgreSQL에 읽기 전용으로 연결하여, sql_agent가 외부 DB 테이블도 자연어로 조회할 수 있습니다.

```
db/external/
├── base.py                # BaseExternalDB ABC (플러그인 인터페이스)
├── postgresql_plugin.py   # PostgreSQL 플러그인 (psycopg2 커넥션 풀)
├── __init__.py            # 팩토리 (db_type → 플러그인 인스턴스)
└── registry.py            # 연결 등록/관리 + 스키마 동기화
```

### 쿼리 라우팅

```
사용자 질의 → orchestrator → sql_agent
                                 ↓
                         LLM SQL 생성
                                 ↓
                         _detect_query_target(sql)
                                 ↓
                  ┌──────────────┼──────────────┐
                  ▼              ▼              ▼
              internal       external:erp     mixed
              (기존 DB)      (외부 커넥터)     (에러 반환)
```

- 외부 테이블은 catalog_tables에 `source_file = 'external:{name}:{table}'` 패턴으로 등록
- `execute_select()`에서 SQL의 테이블을 파악하여 내부/외부 자동 라우팅
- 내부+외부 혼합 조인은 차단 (별도 조회 안내)
- 외부 DB는 **읽기 전용** (SELECT만 허용)

## 알림 시스템

이벤트 발생 시 Webhook, Slack, Teams로 알림을 전송합니다.

```
notifications/
├── events.py              # 이벤트 상수 + 패턴 (file.*, job.*, mart.*, approval.*)
├── dispatcher.py          # emit_event() — 구독 매칭 + 비동기 전송
├── schema.sql             # notification_subscriptions + notification_log 테이블
└── senders/
    ├── base.py            # BaseSender ABC
    ├── webhook.py         # WebhookSender (HMAC 서명 지원)
    ├── slack.py           # SlackSender (Block Kit 포맷)
    ├── teams.py           # TeamsSender (MessageCard 포맷)
    └── __init__.py        # get_sender() 팩토리
```

- 이벤트 패턴: fnmatch 와일드카드 (`file.*`, `job.*`, `*` 등)
- 전송 실패는 호출자에게 전파되지 않음 (silent failure)
- 구독 캐시: 60초 TTL, `invalidate_cache()`로 즉시 갱신

## DB 스키마

`db/init.sql`에 정의된 12개 테이블:

| 테이블 | 용도 | 주요 컬럼 |
|---|---|---|
| `users` | 사용자 인증 | username, password_hash, salt, role (admin/user) |
| `catalog_tables` | 테이블 메타데이터 | table_name, source_file, row_count, description, tags[], column_descriptions |
| `catalog_documents` | 문서 메타데이터 | doc_name, source_file, chunk_count, summary_text, status |
| `catalog_images` | 이미지 메타데이터 | image_name, EXIF 필드들, embedding_dim, thumbnail_path, duplicate_group_id |
| `audit_log` | 감사 로그 | action_type, user_id, query_text, sql_generated, status, metadata |
| `batch_jobs` | 배치 작업 정의 | job_name, sql_text, cron_expr, is_active, last_status |
| `batch_job_history` | 배치 실행 이력 | job_id, status, rows_affected, error_message, execution_time |
| `approval_requests` | 승인 요청 | request_type, sql_text, sql_category, status, metadata (JSONB) |
| `file_process_log` | 파일 처리 이력 | file_path, action, target_table, status, error_message |
| `llm_settings` | LLM 런타임 설정 | setting_key, setting_value, is_encrypted |
| `notification_subscriptions` | 알림 구독 | event_pattern, channel, target, secret, enabled |
| `notification_log` | 알림 발송 이력 | event_type, channel, target, status, error_message |
