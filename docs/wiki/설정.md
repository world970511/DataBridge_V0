# 설정

## .env 전체 옵션

`.env.example`을 `.env`로 복사한 후 수정합니다.

### 감시 폴더

```bash
# 호스트 OS의 공유 폴더 경로 (Docker 볼륨 마운트용)
WATCH_DIR_HOST=/mnt/shared/data        # Linux
# WATCH_DIR_HOST=C:/SharedData         # Windows (슬래시 사용)

# 컨테이너 내부 경로 (변경 불필요)
WATCH_DIR=/data
```

> 공유 폴더는 `:ro` (읽기 전용)로 마운트됩니다. DataBridge가 원본 파일을 수정하지 않습니다.

```bash

# 초과 시 카탈로그 등록만 하고, 질의 시 온디맨드로 파싱
```

### 이미지 처리 (DINOv2)

```bash
DINO_MODEL=dinov2_vits14               # DINOv2 모델 (기본값 권장)

IMAGE_SIMILARITY_THRESHOLD=0.98        # 중복 판정 임계값 (이 이상이면 중복)
IMAGE_NEAR_DUPLICATE_THRESHOLD=0.90    # 유사 이미지 임계값
IMAGE_THUMBNAIL_SIZE=256               # 썸네일 크기 (px)
IMAGE_THUMBNAIL_DIR=/app/thumbnails    # 썸네일 저장 경로 (컨테이너 내부)
IMAGE_MAX_SIZE_MB=50.0                 # 처리할 최대 이미지 크기
IMAGE_COLLECTION_NAME=images           # ChromaDB 컬렉션명
```

### 외부 DB 연결

외부 PostgreSQL에 읽기 전용으로 연결하여, 채팅에서 외부 DB 데이터를 자연어로 조회할 수 있습니다.

```bash
EXTERNAL_DB_ENABLED=true               # 외부 DB 활성화
EXTERNAL_DB_NAME_ALIAS=erp             # 연결 이름 (레지스트리 키)
EXTERNAL_DB_TYPE=postgresql            # DB 종류 (현재 postgresql만 지원)
EXTERNAL_DB_HOST=192.168.1.100         # 외부 DB 호스트
EXTERNAL_DB_PORT=5432                  # 포트
EXTERNAL_DB_NAME=company_erp           # 데이터베이스명
EXTERNAL_DB_USER=readonly              # 사용자 (읽기 전용 권장)
EXTERNAL_DB_PASSWORD=xxxxx             # 비밀번호
EXTERNAL_DB_MAX_CONNECTIONS=3          # 커넥션 풀 크기
EXTERNAL_DB_QUERY_TIMEOUT=30           # 쿼리 타임아웃 (초)
```

> 외부 DB는 **읽기 전용** (SELECT만 허용)입니다.
> 관리자 페이지 > 시스템 상태에서 연결 상태 확인 및 스키마 동기화가 가능합니다.

### 알림 시스템

이벤트 발생 시 Webhook, Slack, Teams로 알림을 전송합니다.

```bash
NOTIFICATION_ENABLED=true              # 알림 시스템 활성화
NOTIFICATION_TIMEOUT=10                # HTTP 전송 타임아웃 (초)
NOTIFICATION_MAX_RETRIES=2             # 전송 실패 시 재시도 횟수
NOTIFICATION_RETRY_DELAY=1.0           # 재시도 간 대기 시간 (초)
```

> 구독 관리는 관리자 페이지 > 알림 설정 탭에서 할 수 있습니다.

## 파일 분류 규칙

`watcher/classifier.py`에서 확장자 기반으로 파일을 자동 분류합니다.

| 확장자 | 분류 | 처리 |
|---|---|---|
| `.xlsx`, `.xls`, `.csv`, `.tsv`, `.json` | 정형 데이터 | DB 테이블로 적재 |
| `.pdf`, `.hwp`, `.hwpx`, `.docx`, `.doc`, `.pptx`, `.ppt` | 비정형 문서 | 텍스트 추출 → ChromaDB 검색 등록 |
| `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.tiff`, `.webp` | 이미지 | DINOv2 임베딩 + EXIF 추출 → ChromaDB 등록 |
| `~$*`, `*.tmp`, `Thumbs.db` 등 | 무시 | 처리하지 않음 |

> 📌 **스마트 분류**: 엑셀 파일이라도 내용이 보고서 형식(텍스트 위주, 숫자 컬럼 비율 낮음)이면 자동으로 문서로 처리합니다. (`watcher/content_analyzer.py`)

## AI 모델 선택 가이드

### GPU 없을 때

- 동작은 합니다. 다만 응답이 느립니다 (10초~1분+)
- 경량 모델 추천: `gemma2:2b` (~1.6GB)
- 처음에 CPU로 써보고, 유용하면 GPU를 추가하는 걸 추천합니다

### 폐쇄망 vs 인터넷 환경

| 환경 | 권장 |
|---|---|
| **폐쇄망** | Ollama + `exaone3.5:7.8b` 또는 `gemma2:2b` |
| **인터넷 가능** | 상용 모델 (OpenAI `gpt-4o-mini`, Anthropic 등) |
| **하이브리드** | 오케스트레이터는 상용, 에이전트는 로컬 |

### 오케스트레이터 / 에이전트 분리

웹 UI의 **⚙️ 설정** 페이지에서 변경 가능합니다.

- **오케스트레이터**: 질의 의도를 분류 (sql / doc / image / composite / mart / job)
- **에이전트**: 실제 SQL 생성, 문서 검색 등 수행

각각에 다른 프로바이더/모델을 지정할 수 있습니다.

## LLM 런타임 설정

웹 UI의 **⚙️ 설정** 페이지 (관리자 전용)에서 **재시작 없이** LLM 모델을 변경할 수 있습니다.

DB의 `llm_settings` 테이블에 저장되며, `.env`보다 우선 적용됩니다.

| 설정 키 | 설명 |
|---|---|
| `orchestrator_provider` | 오케스트레이터 프로바이더 (`ollama` / `openai` / `anthropic`) |
| `orchestrator_model` | 오케스트레이터 모델명 |
| `orchestrator_api_key` | 오케스트레이터 API 키 (상용 모델용) |
| `orchestrator_base_url` | 오케스트레이터 API URL |
| `agent_provider` | 에이전트 프로바이더 |
| `agent_model` | 에이전트 모델명 |
| `agent_api_key` | 에이전트 API 키 |
| `agent_base_url` | 에이전트 API URL |
| `airgapped_mode` | 폐쇄망 모드 (`true`면 상용 API 비활성화) |
